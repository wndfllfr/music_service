# Music Service API

## Описание проекта

Music Service API — веб-сервис для хранения и обработки информации о музыкальных произведениях.

Проект разработан на Python с использованием Flask и Flasgger.

## Модель данных

Каждое музыкальное произведение содержит следующие поля:

| Поле | Описание |
|---|---|
| id | Уникальный идентификатор |
| title | Название произведения |
| artist | Исполнитель |
| genre | Музыкальный жанр |
| duration | Длительность в секундах |
| release_year | Год выпуска |
| bpm | Темп произведения |
| rating | Рейтинг |
| plays_count | Количество прослушиваний |

## Возможности API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/api/music` | Получение всех произведений |
| GET | `/api/music/{music_id}` | Получение произведения по ID |
| POST | `/api/music` | Добавление произведения |
| PUT | `/api/music/{music_id}` | Обновление произведения |
| DELETE | `/api/music/{music_id}` | Удаление произведения |
| GET | `/api/music/sort` | Сортировка записей |
| GET | `/api/music/statistics` | Статистика числовых полей |

## Используемые технологии

- Python
- Flask
- Flasgger
- Pytest

## Запуск проекта

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить приложение:

```bash
python main.py
```

## Документация API

После запуска приложения Swagger доступен по адресу:

`http://127.0.0.1:5000/apidocs`

## Запуск тестов

```bash
pytest -v
```

## Хранение данных

В текущей версии проекта данные хранятся в списке Python в оперативной памяти. После перезапуска приложения изменения сбрасываются.
